### 🔐 Building: Execlave (Founder & CTO)

Most AI agents are kept in line by a system prompt that says *please be careful*. That's a suggestion, not an authorization boundary.

Execlave checks every agent action against your policy **before** it runs. It then allows the action, holds it until a person approves, or blocks it. Each decision goes into a tamper-evident, hash-chained audit log, so compliance evidence comes from what actually happened rather than from a questionnaire.

```python
exe.enforce_policy(agent_id="support-bot", input=request, tools=["issue_refund"])
# $4,200 refund, policy says >$500 needs a manager → held until a human says yes.
```

Open-source SDKs: [Python](https://github.com/execlave-ai/execlave-python-sdk) · [TypeScript](https://github.com/execlave-ai/execlave-js-sdk). Works with LangChain, OpenAI Agents SDK, CrewAI, LlamaIndex, AutoGen and MCP.
